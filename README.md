# Evaluating AI-Generated Clinical Codelists Using CPRD Aurum Dictionaries

MSc Dissertation — Jiaming Liu (jiamingliu776@gmail.com)

## Overview

This project evaluates whether large language models (LLMs) can autonomously generate clinical codelists for epidemiological research using an **agentic Retrieval-Augmented Generation (RAG)** approach. The LLM is given two tools — `search_dictionary` (embedding-based semantic search over CPRD Aurum) and `submit_codelist` (final output) — and autonomously decides what to search and when to stop.

## Models Evaluated

| Model | Model ID |
|---|---|
| GPT-5.4 Mini | `gpt-5.4-mini` |
| Claude Sonnet 5 | `claude-sonnet-5` |
| Gemini 3.6 Flash | `gemini-3.6-flash` |

## Conditions (10)

**Cardiovascular (6):** Atrial Fibrillation, Heart Failure, Cerebrovascular Disease, Hypertension, Myocardial Infarction, Peripheral Arterial Disease

**Respiratory (2):** COPD, Asthma

**Drug Products (2):** Insulin, Metformin

## Pipeline Architecture

1. **Embedding**: CPRD Aurum medical (291,711 codes) and product (79,931 codes) dictionaries are pre-embedded using OpenAI `text-embedding-3-large` (1536 dimensions)
2. **Agentic loop**: The LLM receives a system prompt and iteratively calls `search_dictionary` (returns top-K cosine-similar codes) and decides which codes to include
3. **Submission**: The LLM calls `submit_codelist` with selected code IDs when satisfied
4. **Evaluation**: AI codelists are compared against published reference codelists using Precision, Recall, F1, and Jaccard Index

## Results

Results are in `results_agentic/`:

- `evaluation_results_all.csv` — Main evaluation metrics (P, R, F1, Jaccard) for all 30 condition×model combinations
- `*_codelist.csv` — AI-generated codelists (code IDs)
- `*_log.txt` — Search query logs showing the LLM's autonomous search strategy
- `af_expert_pairwise.csv` — Inter-expert agreement (5 AF codelists, 10 pairwise Jaccard)
- `af_ai_vs_experts.csv` — AI model vs each AF expert
- `fp_error_analysis.csv` / `fn_error_analysis.csv` — Error pattern classification
- `fp_examples.csv` — Example FP codes by error category

## Data Requirements (not included)

The following data files are required but not included in this repository due to licensing restrictions:

- **CPRD Aurum dictionaries**: `CPRDAurumMedical.txt`, `CPRDAurumProduct.txt` (available from [CPRD](https://cprd.com/))
- **Pre-computed embeddings**: `med_embeddings.npy`, `prod_embeddings.npy` (generated by `embed_dictionary.py`)
- **Reference codelists**: Sourced from [ClinicalCodes](https://clinicalcodes.rss.mhs.man.ac.uk/), [HDR UK Phenotype Library](https://phenotypes.healthdatagateway.org/), and [LSHTM Data Compass](https://datacompass.lshtm.ac.uk/)

## API Keys Required

Set the following environment variables before running:

```bash
export OPENAI_API_KEY="your-key"        # For embeddings + GPT
export ANTHROPIC_API_KEY="your-key"     # For Claude
export GEMINI_API_KEY="your-key"        # For Gemini
```

## Reproduction

```bash
# 1. Embed the dictionaries (one-time, ~30 min)
python embed_dictionary.py

# 2. Run the full pipeline
python rag_pipeline_v3.py

# 3. Run error analysis
python error_analysis.py
```
